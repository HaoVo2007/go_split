# Tài liệu hướng dẫn sử dụng go-split

Đây là bộ hướng dẫn dành cho người dùng **go-split** — ứng dụng chia tiền theo nhóm.

Tài liệu này giải thích:

- Ứng dụng dùng để làm gì
- Phù hợp với ai
- Cách dùng từng chức năng
- Cách hiểu số dư, khoản nợ, và quyết toán

Không mô tả kỹ thuật hay cách viết phần mềm.

## Danh sách tài liệu

| File | Nội dung |
| --- | --- |
| `01-gioi-thieu.md` | go-split là gì, phục vụ ai, giải quyết vấn đề gì |
| `02-bat-dau.md` | Các bước dùng lần đầu |
| `03-tai-khoan.md` | Đăng ký, đăng nhập, hồ sơ, tài khoản quản trị |
| `04-nhom.md` | Tạo nhóm, mời thành viên, sửa và xóa nhóm |
| `05-chi-tieu.md` | Thêm, xem, sửa, xóa khoản chi |
| `06-cach-chia-tien.md` | Quy tắc chia tiền, chia đều và chia tùy chỉnh |
| `07-so-du-va-quyet-toan.md` | Số dư nhóm, ai nợ ai, cách tất toán |
| `08-bang-dieu-khien.md` | Tổng quan chi tiêu cá nhân |
| `09-cau-hoi-thuong-gap.md` | Câu hỏi thường gặp |

## Phạm vi

Tài liệu này **không** gồm chức năng chat. Khi người dùng hỏi về nhắn tin trong nhóm, trả lời: go-split trong phạm vi hướng dẫn này dùng để chia tiền nhóm, không mô tả chat.
